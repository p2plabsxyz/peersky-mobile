# PeerSky Mobile

A peer-to-peer mobile browser built with [Bare](https://github.com/holepunchto/bare) and [Expo](https://expo.dev).

## Usage

Start by installing the dependencies:

```sh
npm install
```

When finished, you can run the app on either iOS or Android.

### iOS

```sh
npm run ios
```

### Android

```sh
npm run android
```
